# 《分成两半的子爵》读后感改写设计

## 目标

在 `_reading/Il-viscount-dimezzato.md` 现有草稿的基础上补充完善，保留作者的第一人称阅读感受和提问方式，用简洁、连续的论证回答：卡尔维诺怎样表达对完整人生的追求。

## 核心观点

卡尔维诺追求的不是一种从未被社会摧残的人生，而是人在经历战争、社会角色和道德观念的切割之后，仍然不只活成自己的某一半，能够重新容纳善恶、欲望、局限与经验的完整人生。

## 文章结构

1. 从“为什么一定要把子爵分成两半”的阅读疑问进入文章。
2. 说明分裂首先由战争造成，善恶只是分裂以后呈现出的两种片面状态。
3. 合并分析恶的一半与善的一半：前者把自身残缺强加给世界，后者把绝对的善变成对别人的道德压力；两者都无法真正理解具体的人。
4. 说明重新合为一体不是回到受伤以前，而是带着两半分别生活过的经验，成为更明智但仍不完美的人。
5. 以“仅仅一个完整的子爵不足以使全世界变得完整”收束：个人完整不能消除社会伤害，但能使人不被伤害永久定义。

## 写作约束

- 标题改为《〈分成两半的子爵〉：完整不是没有受伤》。
- 正文约 1800—2500 个汉字，避免重复解释。
- 保留“我一开始……后来……”的思考过程，不改成学院论文语气。
- 完整保留草稿中的两段引文；分别用来说明“分裂带来新的认识”和“重新完整并不等于世界完整”，并整理引文前后的承接关系。
- 不逐段复述情节，每一处情节都必须服务于下一步结论。
- 结尾简短联系《通向蜘蛛巢的小径》和《烟云·阿根廷蚂蚁》，不展开成新的主题。
- 文章正文之外，向作者提供几条针对本稿的写作建议。
