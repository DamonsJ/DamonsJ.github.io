# 快速平方根倒数博客设计

## 目标

在 `_math` 目录新增一篇中文博客，以通俗但严谨的方式解释经典快速平方根倒数算法 `Q_rsqrt`。文章需要回答两个核心问题：`0x5f3759df` 为什么能给出不错的初值，以及随后的一次牛顿迭代为什么能显著提高精度。

目标读者了解基础 C/C++ 语法和高中数学，但不要求预先掌握 IEEE 754、数值分析或牛顿法。

## 文章定位

- 类型：原创整理与推导。
- 叙事方式：从经典代码出发，逐行追问其数学依据。
- 语气：沿用 `_math` 现有文章的中文讲解风格，避免过度学术化。
- 严谨性：明确区分浮点数值与相同 32 位数据对应的整数位模式；标明对数线性化是近似而非恒等式。
- 工程视角：解释原始代码中的严格别名与整数宽度问题，并给出现代 C++20 写法。

## 内容结构

1. **经典代码与问题**
   - 展示 `Q_rsqrt`。
   - 说明它近似计算 `1 / sqrt(x)`，并指出最令人困惑的两行代码。

2. **为什么需要平方根倒数**
   - 用向量归一化说明其历史用途。
   - 只提供理解算法所需的背景，不扩展成游戏史文章。

3. **IEEE 754 单精度浮点数**
   - 介绍符号位、8 位指数和 23 位尾数。
   - 对正的正规数写出浮点值公式。
   - 定义整数位模式 `I_x = 2^23 E_x + M_x`，避免复用 `x` 表示两种不同对象。

4. **位模式为何近似对数**
   - 对浮点值取以 2 为底的对数。
   - 将 `log2(1+m)` 在 `[0, 1)` 上作线性近似，并引入用于修正误差的常数。
   - 推出 `log2(x)` 与整数位模式 `I_x` 近似线性相关。

5. **魔法数的来源**
   - 从 `y = x^(-1/2)` 和 `log2(y) = -1/2 log2(x)` 出发。
   - 推出 `I_y ≈ C - (I_x >> 1)`。
   - 解释右移一位对应乘以 `1/2`，常数用于补偿指数偏置和尾数近似。
   - 区分理论近似常数与 `0x5f3759df`；说明后者经过误差优化，且目标函数和牛顿迭代次数会影响最佳常数。

6. **牛顿迭代**
   - 固定输入 `x`，令 `g(y) = 1/y^2 - x`。
   - 从牛顿法通式推导 `y_new = y(1.5 - 0.5xy^2)`。
   - 逐项对应代码，并说明一次与两次迭代的精度、成本差异。

7. **边界与现代写法**
   - 说明经典算法主要面向正的正规 `float`。
   - 简述零、负数、无穷、NaN 和次正规数不是原推导的正常输入域。
   - 使用 `std::uint32_t` 与 `std::bit_cast` 给出 C++20 实现，避免指针类型转换引起的未定义行为。

8. **今天还应该使用吗**
   - 不做脱离平台的固定性能承诺。
   - 指出现代编译器、SIMD/硬件倒数平方根指令和标准库优化会改变性能结论。
   - 建议先测量误差和性能，再决定是否采用。

9. **总结与参考资料**
   - 总结算法的价值在于将数据表示、近似数学与迭代法连接起来。
   - 保留用户材料中的 Tim Hutt 与 Better Explained 链接，并补充可靠来源。
